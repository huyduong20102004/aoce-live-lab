# Lịch sử Windows Task Scheduler

Task `AOCE-PortalLite-Live-Smoke` đã được tắt sau khi kiểm chứng GitHub scheduled run thành công. **GitHub là lịch chính**. Các định nghĩa XML, status và invocation ở đây được giữ làm bằng chứng lịch sử của phép thử local.

- [Báo cáo kiểm chứng OS trigger ban đầu](schedule-evidence.md).
- [Task definition daily](windows-schedule.xml), [task one-time](windows-schedule-verified-once.xml).
- [Status đã ghi nhận](windows-schedule-status.json), [verification ban đầu](windows-schedule-verification-final.json).
- [Invocation history](scheduler-invocations.jsonl).
- [Nguyên nhân chạy trễ và trạng thái đã tắt](../recovery/README.md).

Các dòng "next run" và "pending" trong snapshot cũ không thể hiện trạng thái task hiện nay. Quay lại [mục lục live](../README.md).
